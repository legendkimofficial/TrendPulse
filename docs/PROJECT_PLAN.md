# Trend Pulse 구현 및 검증 계획

Trend Pulse는 GDELT Article List(GAL)에 수록된 여러 나라 언론사의 영어 기사 제목에서 화제 키워드를 추출한다. 기본 화면은 최근 7일 감쇠 순위와 보도 매체·발행국 수를 보여준다. 72시간 화면은 직전 72시간과 비교해 보도 비중이 증가한 키워드를 보여준다.

필수 제출 범위는 연속 7일의 고정 데이터 재생, 7일 순위, 72시간 급상승, 감쇠 윈도우 및 DGIM 비교 실험, 실제 Upstage Solar 시연이다. 주기적 기사 수집은 추가 목표이며, 30일 추이는 후속 범위다. 고정 재생과 주기 수집은 같은 기사 형식과 집계 코드를 공유한다. 주기 수집에는 신규 배치 판별, 재시도, 재시작 지점 저장, 중복 방지, 마지막 성공 시각 표시가 추가된다. 시연용으로 실행 중에만 갱신하는 범위면 수집기 확장으로 처리할 수 있다.

## 구성과 완료 기준

| 영역 | 구성 | 완료 기준 |
|---|---|---|
| 데이터 | GAL 연속 7일분을 확보하고 관측 시각순으로 재생한다. 영어 기사와 발행국을 확인한 매체를 분석에 사용한다. | 입력 해시, 일별·매체별·발행국별 기사 수, 중복 제거량과 수집 공백이 기록된다. 같은 입력은 같은 순서로 재생된다. |
| 7일 화제 순위 | 최근 7일의 기사에 경과 시간 기준 감쇠를 적용한다. 반감기 48시간을 초기 실험값으로 둔다. | 7일 경계와 점수 계산을 검증하고, 전체 키워드를 유지하는 방식과 낮은 점수의 키워드를 제거하는 방식의 메모리·순위 일치율·진입 지연을 비교한다. |
| 72시간 급상승 | 최근 72시간과 직전 72시간의 키워드 포함 기사 비율을 비교한다. | 두 구간의 데이터가 확보된 시점에서 급상승 결과를 재현하고, 근거 기사와 보도 매체를 확인할 수 있다. |
| DGIM | 선택한 키워드가 추적 시작 후 최근 N개 기사에 등장한 횟수를 추정한다. | 동일 범위의 정확 집계와 비교해 오차와 저장 비용을 기록한다. |
| 웹과 Solar | 화제 순위, 급상승 목록, 근거 기사와 Solar 답변을 연결한다. | 실제 도구 호출과 기사 인용을 확인하고, 새 환경에서 데이터 준비부터 시연까지 재현한다. |
