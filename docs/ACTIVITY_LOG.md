**검증과 발견한 문제 (15:45~16:00)**
- 방법: Edge 헤드리스 스크린샷으로 1차 확인 → 가상환경에 Playwright를 설치하고 로컬 Edge(channel msedge)로 1440/1180/390px에서 보기 전환·패널·대화상자·재생·에이전트 질문을 자동 실행, 콘솔 오류와 뷰포트 밖 요소를 측정.
- 문제 1: 상세 패널에 커다란 검은 덩어리 → `<a class="btn">` 안의 SVG 아이콘에 크기 규칙(`button svg`)이 적용되지 않아 기본 300×150으로 그려짐. `.btn svg` 규칙으로 수정.
- 문제 2: 정확 비교 차트의 주황 곡선 아래 검은 띠 → 호버용 투명 경로가 곡선이라 SVG 기본 `fill: black`으로 면이 채워짐. `fill: none` 추가.
- 문제 3: 헤드리스 스크린샷에서 폰 너비 가로 넘침처럼 보임 → Playwright 측정 결과 `scrollWidth = 390`, 넘치는 요소 0. 스크린샷 도구(가상 시간·창 크기) 특성으로 판단. 다만 이 과정에서 `.page` 그리드 열을 `minmax(0, 1fr)`로 고정하고 표에 가로 스크롤 보호를 넣음.
- 문제 4: 첫 bump chart는 스냅샷 60개·직선·"밖" 행까지 그려 읽기 어려움 → 최근 36개, 수평 접선 베지어 곡선, Top 10 밖 구간은 선을 끊는 방식으로 변경.
- 문제 5: `index.html`에 CSV 버튼을 추가한 뒤 데모 딥링크가 "초기화 실패" → Flask가 `debug=False`에서 템플릿을 캐시해 옛 HTML을 내려줌. 서버 재시작으로 해결(앞으로 템플릿 수정 시 재시작).
- 문제 6: 새 API 테스트가 기본 날짜 모드(최근 10일 창, 기사 300건)에서는 "근거 얇음"이 성립하지 않음 → 테스트를 기사 수 모드 `c=0.05`(창 20건)로 명시.
- 결과: 테스트 **67개 통과**(신규 17개), Playwright 검사 **콘솔 오류 0 · 가로 넘침 0**, 데모 장면(`/?demo=1`)에서 정확 비교 보기에 `gop`↔`scalia` 역전이 표시됨을 확인하고 README 스크린샷으로 사용.
