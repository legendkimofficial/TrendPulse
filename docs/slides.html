감쇠 윈도우로 순위, DGIM으로 보조 집계

감쇠 윈도우 + 제거 주 기능

score(w) ← score(w)·(1−c)단계 + 1[w ∈ 새 기사]
  • 단계 = 기사 1건 또는 날짜 1일(v0.3 기본, 반감기 7일)
  • 점수 < θ(0.5) 키워드는 삭제, 잃는 점수 < θ/(1−θ)
  • v0.3: 키워드가 다시 들어온 뒤 경과만큼 상한이 줄어드는 키워드별 상한

DGIM 보조 기능

최근 N개 기사 중 키워드 등장 기사 수 ≈ ?
  • 크기 2k 버킷, 크기별 최대 r개, 상대오차 ≤ 1/(2(r−1))
  • Top K 진입 시 자동 추적, 추적 시작 이후만 계수 → "관측 n/N건"
  • 용량 300개: 현재 Top K·고정 키워드는 유지, 오래 비활성인 자동 추적부터 교체

단위 테스트 50개: 단순 구현과의 일치, 오차 상한, 불확실성 표시 보장, 추적 정책, 설정 검증, Solar 근거 검증(mock)

실험 3 · 날짜 감쇠의 대가 v0.3

희소 구간에서는 어느 쪽이든 근거가 얇다

기사 수 감쇠는 몇 달 전 기사가 순위를 지탱하고, 날짜 감쇠는 최근 기사를 반영하지만 하루 5건이라 1~2건짜리 키워드도 오른다. 2019년 이후 Top 20의 73~78%(기사 수 감쇠는 81~88%)가 최근 7일 기사 ≤ 2건

급상승 · 순위 불확실성 v0.3

급상승은 더 빨리, ≈ 표시는 필요한 곳에만

급상승 = 짧은 점수 − 긴 점수로 예상한 값

화면: 2019-04-16 노트르담 화재 다음 날의 급상승 패널

  • 사건 26개 중 24개를 7일 안에 급상승 Top 10에 올림 (Top 20은 16개)
  • 17개 사건에서 Top 20보다 먼저, parkland는 급상승에서만 +1일
  • 급상승 목록의 48%는 그 시점 Top 20에 없는 키워드

≈ 표시의 보장

  • 정확 점수 ∈ [s, s + e): 아래 키워드가 si+1 + ei+1 > si일 때만 ≈
  • 인접 쌍 37,905개 중 놓친 역전 0건, 표시는 66.6% → 2.4%
  • 대가: 키워드별 진입 시점 기억 → 객체 크기 +29.6%
급상승: 단어+구 · 기사 수 감쇠 기준 (날짜 감쇠 기본에서는 22/26) · 불확실성: 단어 · 기사 수 감쇠, 원점수 기준10
실험 4 · DGIM (보조 기능)

DGIM의 이득은 "무엇으로 재느냐"에 따라 달라진다

논리 저장량(압축 가정)으로는 N=500에서 DGIM이 103%로 손해, N=5,000에서 39%로 이득. Python 실측으로는 모든 구성에서 DGIM이 더 작음(34~85%) — 정확 쪽 deque의 고정 비용 때문. 두 수치를 섞지 않는다

오차는 모두 이론 상한 안. 중앙값 추정의 평균 오차 7.9% vs 교과서식 26.7%는 등장 1~4회에서 생긴 차이(6.4% vs 32.2%). 10회 이상은 11.0% vs 11.1%, Top 10 겹침도 같음
